MPI Matrix Performance Lab

Comparación de ejecución secuencial y paralela con cuatro procesos MPI. Las cifras provienen del archivo resultados.csv del repositorio, no de una simulación.

Origen y limitaciones

Datos tomados de resultados.csv. El archivo también contiene registros textuales mezclados con filas CSV; conviene separar la salida de consola de los datos tabulares. Para N=2 el tiempo secuencial figura como 0 y no permite un speedup confiable.

Estas son mediciones históricas sin información completa de hardware, repetición ni dispersión. No constituyen una garantía de rendimiento. Esta página no ejecuta MPI; muestra y calcula métricas de los resultados registrados.

Propuesta de evolución
Proyecto académico de computación paralela · visualización local de datos experimentales
